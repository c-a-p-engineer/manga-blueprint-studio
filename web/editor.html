はじめての使い方

難しい漫画用語を覚えなくても、ページ→コマ→キャラ→背景→文字→演出の順に決めれば使えます。

  1. 原稿サイズとコマ割りを選ぶ迷ったら「現行サイズ」と「アクション3コマ」、または「おまかせ作成」で開始。
  2. コマをタップしてキャラを置く棒人間は外見ではなく、位置とポーズをAIへ伝える設計図です。
  3. カメラ・背景・吹き出し・演出を決める専門語には「超寄り」「あおり」のような日本語説明を併記しています。
  4. AI用PNG + JSON + Promptを出力AI用PNGからキャラ名やコマ番号は除去され、描画してよい文字だけPromptへ渡されます。
