漫画のページ設計から始める

Manga Blueprint Studio の使い方

このツールは、作品 → ページ → コマの順に漫画の設計を決め、その設計図をAIへ渡すためのエディタです。

作品
  → 必要なら 巻 / 章 / フォルダ
    → P001, P002, ...
      → ページ設定 / コマ割り
        → コマ・キャラ・背景・文字・演出
          → 選択中ページの AI生成ZIP
巻・章・フォルダは任意です。 短い漫画なら「作品 → P001 → P002 …」だけで使えます。

最初の5分

  1. 作品を開く / 作る作品名をタップすると作品エクスプローラーを開けます。
  2. P001を選ぶページバーか「作品エクスプローラー」からページを選びます。
  3. ページ設定を決める原稿サイズ、読み方向、画風、コマ割り、ストーリーテンプレートなどを決めます。
  4. コマをタップして中身を詰めるカメラ、コマ形状、人物、背景、吹き出し、演出を編集します。
  5. 出力 → AI生成ZIP選択中の1ページをZIPにして画像生成AIへ渡します。

画面の見方

① アプリヘッダー

アプリ全体の操作だけを置きます。スマホでは、上段をタイトルと説明、下段を「使い方 / 元に戻す / やり直す / 言語」にした2段ヘッダーです。

② 作品・ページ位置

作品名、パンくず、現在ページ P001、前後移動、ページ追加、作品エクスプローラーがあります。

③ 漫画キャンバス

現在ページのコマ割りを確認します。コマ・人物・吹き出しをタップして編集対象を選びます。

④ 下の編集タブ

ページ設定 / コマ / キャラ / 背景 / 文字 / 演出 / 出力。現在のページや選択中のコマを編集します。

作品エクスプローラー：ファイルエクスプローラー感覚でページを探す

作品エクスプローラーは漫画の階層を一覧するメインナビゲーションです。

ロボ漫画
├─ P001  表紙
├─ 第1巻
│  ├─ 第1章
│  │  ├─ P002  登場
│  │  └─ P003  対峙
│  └─ P004
└─ P005

巻・章・フォルダは必要な作品だけ使ってください。ページは作品直下にも置けます。

P001とは？ ページ番号1を P001 と見やすく表示しているだけです。8ページ目は P008、42ページ目は P042 です。

ページ設定：そのページをどう作るか

ページ設定はページを探す場所ではなく、今開いているページの原稿・コマ割り・全体方向を決める場所です。

原稿サイズ

標準縦長、SNS向け、B5/A4、Webtoon、カスタムなど。

読み方向

日本漫画の右→左（RTL）が既定。左→右（LTR）にもできます。

コマ割り

通常レイアウトに加えて、斜め3コマ、斜め4コマ 2×2を選べます。

画風・仕上げ

カラー/白黒、線、陰影、描き込み、背景仕上げ、追加の画風・仕上げ指示（任意）を指定できます。

斜めコマ・台形・四隅編集

Prototype 0.16.0 では、斜め枠は見た目だけではなく実際のコマ境界として保存されます。

ページ全体から始める

ページ設定 → コマ割りで「斜め3コマ」「斜め4コマ 2×2」を選ぶと、最初から変形可能な四角形コマでページを作れます。

1コマだけ変形する

コマを選択し、コマ → コマ形状で長方形、左右の斜め、左右の台形を選べます。

四隅を直接動かす

  1. コマを選択キャンバスで対象コマをタップします。
  2. 「四隅を直接編集」青い4つのハンドルが表示されます。
  3. 青い丸をドラッグ四隅を独立して動かせます。
  4. 編集終了Undo/Redoでも戻せます。
安全策： 自己交差、ほぼゼロ面積、極端に短い辺になる移動は拒否されます。変形コマでは現在「断ち切り」を無効化しています。

古い長方形だけの作品はそのまま使えます。変形コマの境界は、画面の枠・タップ判定・クリップ・クリーンPNG・AI向けRender Briefで同じ4点を使います。

コマ割り文法：斜めでも余白を広げない

Prototype 0.18.0 では、隣り合う斜めコマを別々に傾けず、細い共有斜線で分けます。大きな白いV字や中央の十字余白を作りにくくし、絵そのものへ視線を戻します。

対向3コマ（斜め）

上段2コマを共有斜線でつなぎ、下の大ゴマへ落とします。怒り・決定打・発見向け。

ジグザグ4コマ

上下で斜線を反転し、高速な攻防や反撃を右→左→下へ送ります。

段違い4コマ

左右の幅を上下で入れ替え、均等2×2より会話・リアクションへ大小をつけます。

溜め / ディテール → 大ゴマ

小さい情報を積み、決断・発見・見せ場へ大きな面積を渡します。

斜め枠は演出です。 静かな余韻や親密な場面では、読みやすい長方形をあえて使うテンプレートも残しています。

各編集タブ

タブ何を決める？

Story Template と Smart Manga の違い

ストーリーテンプレート / Story Template

「告白」「反撃」「キャラ登場」など、意味の分かる定番の展開から始めたいときに使います。カードを選ぶとそのテンプレートが選択され、閲覧・検索・絞り込みだけではページを変更しません。

カードには使用する主な演出がチップで表示されます。重複していたストーリーテンプレートの選択ドロップダウンは表示しません。

Smart Manga

目的から少しずつ違う候補を見たいときに使います。候補を採用したときだけページへ反映されます。

演出からサンプルを探せます。 1人表示 / 2人表示 / 恋愛 / バトルなどの条件と、演出あり / 演出なし、斜めコマ、衝撃枠、枠無し、小窓、集中線、スピード線、衝撃線、緊張線、無音・間、ブチ抜きを組み合わせて絞り込めます。たとえば「2人表示 + 集中線」「斜めコマ + 衝撃枠」です。`突進→一撃`、`連続攻防`、`衝撃の発見`、`不穏な接近`、`静かな余韻`、`ツッコミ小窓` などをそのまま試せます。

Scene Template / シーンテンプレートという別機能はありません。 正式名称は Story Template / ストーリーテンプレートです。

テンプレートはページ設定の上段で完結します。 カードでコマ割り・演出を選び、「サンプルのセリフ・効果音を使う」のチェックで文字を入れるか決定。使用キャラクターを選んだら、常に表示される「このテンプレートを使う」で適用します。独立した中段のストーリーテンプレート欄はありません。

キャラクター：Character Sheet は必須ではない

Character Sheet

外部シートを見た目の正本として使う方式。

文章で指定

髪、服、体格、特徴などを文章で固定する方式。

AIにおまかせ

簡単な外見をAI側に決めさせる方式。

キャンバスの棒人間は見た目や服装ではなくポーズ・位置・大きさの設計図です。棒人間を裸として解釈せず、キャラクターに設定した服装を完成絵へ使います。
新規作品には6人のスターターがあります。 高校生男子 / 高校生女子 / 成人男性 / 成人女性 / モブ男性 / モブ女性。髪・目に加えて、学校制服や長袖トップス＋ロングパンツ等の服装まで初期指定した編集可能な汎用ベースです。既存作品には自動追加せず、キャラタブの「かんたん追加」から必要なものを足せます。

読み方向と文字方向は別

コマの読み方向

rtl = 日本漫画の右→左、ltr = 左→右。コマ番号と読む順番を決めます。

文字の書き方向

vertical-rl = 縦書き日本語、horizontal-tb = 横書き。

AIへ渡す

現在のAI生成ZIPは選択中の1ページだけを対象にします。

<prefix>_clean.png
<prefix>.manga.json
<prefix>_prompt.txt
<prefix>_manifest.json

最初に *_manifest.json を読ませてください。クリーンPNGはコマ境界と空間配置、JSON/Promptは出来事・カメラ・背景・文字方向などの意味を伝えます。

斜め・台形コマは同じ4点境界がクリーンPNGとRender Briefへ入り、Design Direction Passもその境界を変更できません。

このZIPを展開して、最初に中の *_manifest.json を読んで、その内容に従って漫画を生成してください。
Character Sheet が必要と書かれているキャラクターは、別途添付した Character Sheet 画像を対応付けて使ってください。

困ったとき

スマホのヘッダーが古い1段表示

0.16.0では2段表示です。更新直後に古い表示が残る場合はページを再読込してください。エントリポイントとruntime URLはバージョン付きです。

別ページが見つからない

キャンバス上のページバーか作品エクスプローラーを使います。

生成画像に編集ラベルが出た

確認用注釈PNGではなくAI生成ZIP / clean PNGを使います。

斜めコマを元に戻したい

コマ形状で長方形を選ぶか、Undoを使います。

テンプレートからページを作る

  1. Story Templateを選ぶコマ割り・演出をカードからまとめて選びます。
  2. セリフとキャラを決める「サンプルのセリフ・効果音を使う」のチェックと、使用キャラクターを選びます。
  3. このテンプレートを使う大きな適用ボタンで現在ページへ反映します。直接編集したいときだけ「手動でコマ割りを調整」を開きます。

旧「巻・章・フォルダ」編集欄はページ設定には表示しません。作品名を押して開く 作品エクスプローラー から作品・ページを移動します。
