漫画のページ設計から始める

Manga Blueprint Studio の使い方

このツールは「AIに漫画を丸投げする」画面ではなく、作品 → ページ → コマの順で漫画の設計を決め、その設計図をAIへ渡すためのエディタです。

作品
  → 必要なら 巻 / 章 / フォルダ
    → P001, P002, ...
      → ページ設定 / コマ割り
        → コマ・キャラ・背景・文字・演出
          → 選択中ページの AI生成ZIP
巻・章・フォルダは任意です。 短い漫画なら「作品 → P001 → P002 …」だけで使えます。

最初の5分

  1. 作品を開く / 作る作品名をタップすると作品一覧を開けます。
  2. P001を選ぶキャンバス上のページバーか「作品構成」からページを選びます。
  3. ページ設定を決める原稿サイズ、読み方向、画風、コマ割り、ストーリーテンプレートなどを決めます。
  4. コマをタップして中身を詰める人物、カメラ、背景、吹き出し、演出を必要なところだけ編集します。
  5. 出力 → AI生成ZIP現在の1ページをZIPにして、表示される短い受け渡し文と一緒に画像生成AIへ渡します。

画面の見方

① アプリヘッダー

「使い方」「元に戻す」「やり直す」「日本語 / English」など、アプリ全体の操作だけを置いています。

② 作品・ページ位置

作品名、パンくず、現在ページ P001、前後移動、ページ追加、作品構成があります。ここが「今どこを編集しているか」の場所です。

③ 漫画キャンバス

現在ページのコマ割りと人物・吹き出しなどを確認します。コマや人物をタップすると編集対象になります。

④ 下の編集タブ

ページ設定 / コマ / キャラ / 背景 / 文字 / 演出 / 出力。現在のページや選択中のコマを具体的に編集します。

作品構成：ファイルエクスプローラー感覚でページを探す

作品構成は、漫画の階層を一覧するメインのナビゲーションです。

ロボ漫画
├─ P001  表紙
├─ 第1巻
│  ├─ 第1章
│  │  ├─ P002  登場
│  │  └─ P003  対峙
│  └─ P004
└─ 資料用フォルダ
   └─ P005

ページをタップするとそのページへ移動します。巻・章・フォルダの作成や移動など細かい操作は、同じ画面の詳細操作を開いて行います。

P001とは？ ページ番号1を見やすく P001 と表示しているだけです。8ページ目は P008、42ページ目は P042。ページ名は任意です。

ページ設定：そのページをどう作るか

ページ設定はページを探す場所ではなく、今開いているページの原稿・コマ割り・全体方向を決める場所です。

原稿サイズ

標準縦長、SNS向け比率、B5/A4、Webtoon、カスタムなどを選べます。

読み方向

日本漫画の右→左（RTL）が既定。左→右（LTR）にもできます。コマ番号と読み順に反映されます。

コマ割り

1〜6コマ、4コマ、会話、アクション、クライマックスなどのレイアウトから開始できます。

画風・仕上げ

カラー/白黒、アニメ/漫画/鉛筆/インクなど、線、陰影、描き込み、背景仕上げ、追加指示を作品全体の描き方として指定できます。

「追加の画風・仕上げ指示（任意）」は、例えば 線を細めに。淡い色合い。影は控えめ。 のように普通の日本語で書いて構いません。

各編集タブ

タブ何を決める？
ページ設定原稿サイズ、読み方向、画風、コマ割り、ページ全体の開始パターン
コマそのコマで何が起きるか、カメラ、構図、枠、断ち切り、ブチ抜きなど
キャラ登場人物、見た目の参照方法、ポーズ、表情、視線、位置・大きさ
背景場所、時間、天気、雰囲気、描き込み量、背景の見せ方
文字吹き出し、話者、セリフ、縦書き/横書き
演出集中線・スピード線・衝撃表現、オノマトペ/SFX
出力現在ページをAI生成用または確認用パッケージとして出力

ストーリーテンプレートと Smart Manga の違い

ストーリーテンプレート

「告白」「反撃」「驚く」「キャラ登場」のような、意味の分かる定番の展開から始めたいときに使います。

コマ割り、出来事、カメラ、ポーズ、背景、演出、任意のサンプル台詞などをまとめて提案します。

Smart Manga

「こういう目的のページがほしい」から、複数の少し違う候補を見たいときに使います。

候補を見ただけでは現在ページは変わりません。採用した候補だけを明示的に適用します。

Scene Template / シーンテンプレートという別機能はありません。 正式名称はストーリーテンプレートです。

キャラクター：Character Sheet は必須ではない

再利用キャラクターの見た目は3方式から選べます。

Character Sheet

別途用意したキャラクターシートを正本として使います。必要な場合だけ生成時に別添します。

文章で指定

髪、服、体格、特徴などを日本語の説明で固定します。Character Sheetは不要です。

AIにおまかせ

簡単な外見を生成AI側に決めさせます。ページ内では同じ人物として一貫させる前提です。

キャンバスの棒人間は見た目ではなくポーズ・位置・大きさの設計図です。

読み方向と文字方向は別

コマの読み方向

rtl = 日本漫画の右→左。ltr = 左→右。コマ番号と読む順番を決めます。

文字の書き方向

vertical-rl = 縦書き日本語（既定）。horizontal-tb = 横書き。吹き出しやSFXごとに上書きもできます。

縦書きに変えても、漫画のコマ順は変わりません。

カメラ用語が分からないとき

英語の専門語はAIとの相互運用のため一部残りますが、日本語の意味を主に考えれば構いません。

Extreme close / 超寄り

目・口・手・拳など一部分を大きく見せる。緊張、驚き、決めに向く。

Long / 引き

全身と周囲を見せる。人物の位置関係や動作を読みやすくする。

Low angle / あおり

下から見上げる。強さ、巨大感、迫力、威圧感を出しやすい。

High angle / ふかん

上から見下ろす。位置関係や弱さ・孤立を見せやすい。

Panel Peek / コマ一覧 / Manga Check

Panel Peek はコマの ⓘ または長押しから、出来事・人物・カメラ・背景・台詞・演出などをまとめて確認できます。

コマ一覧はページ全体を読むための一覧です。毎回すべての設定欄を開かなくてもコマの意味を確認できます。

Manga Checkは助言です。出来事が空、カメラが単調、背景が空、人物サイズとカメラ指定が矛盾していそう、といった点を知らせますが、勝手に直したり出力を止めたりしません。

AIへ渡す

現在の出力単位は「選択中の1ページ」です。 複数ページ作品を作れても、まだ作品全部を1つの生成ZIPへまとめる機能ではありません。

AI生成ZIP

画像生成するときはこちらを使います。

<prefix>_clean.png
<prefix>.manga.json
<prefix>_prompt.txt
<prefix>_manifest.json

*_manifest.json が最初に読むファイルです。AIへ渡す短い文章も「まずmanifestを読んで」と指示する形になっています。

確認用 / Review ZIP

同じ意味データに注釈付きPNGを加えた確認・保存向けパッケージです。注釈PNGは制作メタ情報を含むため、通常の画像生成入力にはAI生成ZIPを使います。

ファイルごとの役割

  • Clean PNG：コマ形状、配置、大きさ、ポーズ方向など空間。
  • .manga.json + prompt：何が起こるか、カメラ、背景、文字方向など意味。
  • Character guidance / 必要なCharacter Sheet：人物の見た目。
  • 画風・仕上げ：どんな描き方にするか。
  • TEXT TO RENDER：最終漫画に実際に描いてよいセリフ/SFX。

現在まだ対応していないもの

以下はロードマップ上の次段階以降です。今の画面に似たデータがあっても「もう使える」とは扱いません。

  • 作品全体を完全復元する Backup / Restore ZIP
  • 「P003〜P005」「第1巻」「作品全体」などの複数ページAI出力
  • コマ単位の Panel-first 生成パッケージと自動ページ合成
  • 場所・小物・衣装などをページ跨ぎで固定する汎用Reference Asset
  • 180度線、視線ベクトル、Eye-flow、Gutter、見開きなどの高度な漫画演出契約
  • 生成後の日本語文字を決定論的に最終組版する機能

困ったとき

別ページが見つからない

キャンバス上のページ列か「作品構成」を開いてください。

巻や章を作らないといけない？

不要です。ページを作品直下に置いたまま使えます。

P001の意味が分からない

ページ番号1の見やすい表記です。内部データでは数値の1として管理されています。

AIがキャラ名やカメラ注記まで絵に描いた

通常は「AI生成ZIP」のclean PNGを使ってください。注釈付きPNGは確認用です。正確な表示文字はpromptのTEXT TO RENDERだけが許可対象です。

Character Sheetを作りたくない

キャラクターの見た目方式を「文章で指定」または「AIにおまかせ」にしてください。

英語の項目が分からない

日本語UIでは専門語に日本語説明を添える方針です。主要な操作面に説明のない英語だけが残っている場合はUIの改善対象です。
